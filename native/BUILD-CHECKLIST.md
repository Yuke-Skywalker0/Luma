# Build checklist — V7.2

## Android (Windows/macOS/Linux)
- [ ] Install Node.js 24.x
- [ ] Install Android Studio + Android SDK
- [ ] `npm run install:all`
- [ ] `npm install`
- [ ] Copy `frontend/.env.native.example` to `frontend/.env.production`
- [ ] Set `VITE_API_BASE_URL=https://YOUR-RENDER-SERVICE.onrender.com` (origin, no `/api` suffix)
- [ ] `npm run build:frontend`
- [ ] `npm run native:add:android` (first time only)
- [ ] `npm run native:sync`
- [ ] `npm run native:open:android`
- [ ] In Android Studio, run on a physical device and verify login/search/playback/network state
- [ ] Configure app signing before release

## iOS (requires macOS + Xcode)
- [ ] Complete common setup above on a Mac
- [ ] `npm run native:add:ios` (first time only)
- [ ] `npm run native:sync`
- [ ] `npm run native:open:ios`
- [ ] Configure bundle signing, URL schemes/OAuth, privacy strings and app icon in Xcode
- [ ] Test on a physical iPhone; configure Apple developer signing before distribution

## Do not claim these are already verified
This ZIP contains the Capacitor config and bridge scaffolding. Android/iOS project directories are generated by `cap add` on the development machine. A native binary has not been built or signed by this packaging step.
